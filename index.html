GET STARTED

從第一句話開始。

開啟「設定 → 語音鍵盤首次設定」，跟著 APP 的步驟完成。

  1. 允許麥克風需本人確認並操作

    閱讀手機權限提示，再決定是否允許錄音。

  2. 啟用 WOVEN 鍵盤需本人確認並操作

    到 Android 鍵盤設定啟用 Woven Prompt。

  3. 選擇語音來源

    在「語音與 AI」下載離線模型，或設定自備 Vertex API／雲端服務。

  4. 試說、確認、再送出

    開啟文字欄位，切到 WOVEN。選口述，點說話，說完再點完成。

YOUR DATA, YOUR CHOICE

知道資料送去哪裡，
再決定怎麼使用。

Prompt 在裝置上組合與保存，不會傳給廣告或分析服務。選擇自備 API 或雲端並同意後，本次錄音、文字及辨識提示才會傳到所選服務處理。API／雲端錄音另加密保存在手機錄音庫，可回聽、匯出或刪除。

「你的資料」代表你有選擇與管理的入口；不代表所有模式都離線。分享、備份與開啟外部 AI，皆由你主動操作。
