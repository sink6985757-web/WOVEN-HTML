語音鍵盤、打字鍵盤與文字工具，在同一個 APP 裡各就各位。

01 / VOICE

在文字欄位裡，直接說。

回訊息、記筆記，直接說出內容；想列重點就選自然整理，要草擬文章就選寫作。也能隨便問或翻譯。口述會輸入文字，其他結果可複製或依畫面操作；送出前由你確認。

02 / NOTES

照片和錄音，一鍵整理。

白板、講義拍下來，或選一段錄音，先在手機上轉成文字，改好錯字，再按「整理成筆記」或「整理成會議紀錄」。決議與待辦分開列，沒講到的負責人和期限會寫「未提及」，不亂猜。

03 / WORKFLOW

常用的需求，不必重寫。

常用技能一點就套用：會議紀錄、筆記、可貼上的回覆、待辦清單。也可以自己建立技能，加入背景或審查角度，試跑滿意再存起來；需要時也能產生提示詞，複製到你慣用的工具。

GET STARTED

從第一句話開始。

開啟「設定 → 語音鍵盤首次設定」，跟著 APP 的步驟完成。

  1. 允許麥克風需本人確認並操作

    閱讀手機權限提示，再決定是否允許錄音。

  2. 啟用 WOVEN 鍵盤需本人確認並操作

    到 Android 鍵盤設定啟用 Woven Prompt。

  3. 選擇語音來源

    先下載中文或英文離線語音；也可使用自己的 Google 金鑰。月訂閱已停止新購買，既有訂閱依有效期限使用。

  4. 試說、確認、再送出

    開啟文字欄位，切到 WOVEN。選口述，點說話，說完再點完成。

YOUR DATA, YOUR CHOICE

知道資料送去哪裡，
再決定怎麼使用。

Prompt 在裝置上組合與保存，不會傳給廣告或分析服務。選擇自備 API 或雲端並同意後，本次錄音、文字及辨識提示才會傳到所選服務處理。API／雲端錄音另加密保存在手機錄音庫，可回聽、匯出或刪除。

「你的資料」代表你有選擇與管理的入口；不代表所有模式都離線。分享、備份與開啟外部 AI，皆由你主動操作。
