官方 HTML 公開入口

一個連結，把 Woven Prompt 帶到任何瀏覽器

不用重新安裝 App，也不用每次尋找新版下載位置。從電腦、平板或手機開啟這個固定入口，就能進入目前推薦的 Woven Prompt HTML。

→ 立即開啟 Woven Prompt ↓ 下載離線單檔

入口公開給所有人。 正式離線版使用需匯入透過 Woven Prompt Android App 流程核發給你的個人 License；請勿公開或轉傳該檔案。

打開、驗證，繼續你的 Prompt 工作

同一個首頁串起線上開啟、離線下載與個人 License 驗證。

  • ✓手機與桌面瀏覽器都能開啟
  • ✓個人 License 只在本機驗證
  • ✓使用 WOVEN Backup v3，並相容 v2／v1

知道這個入口，就少記很多事情

把網址加入書籤，之後不論換裝置、重新下載或查看新版，都先從這裡開始。

固定網址

目前推薦版本會從同一個首頁提供，不必在訊息或資料夾裡反覆找連結。

🌐

開瀏覽器就能用

臨時換電腦、平板或手機時，不必先安裝 APK 才能打開 HTML 工作區。

📦

需要時可離線保存

下載單一 HTML 檔即可帶走；資料搬移則使用 WOVEN Backup v3，也能承接 v2／v1。

從 Android App 取得 License，再到 HTML 繼續使用

公開的是入口與共同 HTML；真正屬於你的，是購買後由安全後端驗證並核發的個人 License。兩者分開，方便更新，也不需要把個人資料放進公開網頁。

  1. 1
    從 Android App 進入官方流程 在 Woven Prompt App 內透過 Google Play 完成離線 HTML 一次性購買。
  2. 2
    匯出個人 License 後端驗證成功後，在 App 匯出不含 Email 或訂單明文的 License；請自行妥善保存。
  3. 3
    開啟公開 HTML 入口 回到這個固定網址，按「立即開啟 Woven Prompt」。
  4. 4
    在瀏覽器匯入驗證 License 只在目前瀏覽器本機驗證與保存，之後即可進入工作區。

Prompt 由你決定何時帶到外部 AI

Woven Prompt 只負責整理與組合 Prompt，不內嵌 AI API Key，也不會自動呼叫付費 AI API。只有你主動選擇目的地時，才會開啟外部網站。
